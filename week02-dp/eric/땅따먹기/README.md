# 문제 설명

다음 칸을 밟을 때 같은 열을 제외하고 밟으며, 마지막 행을 밟을 때 누적된 값이 가장 큰 경우를 만들기 위한 칸을 밟아야 함.

# 문제 접근

처음 문제 접근을 가장 큰 값을 밟으면 마지막에 가장 큰 값이겠지? 라고 안일하게 생각했었습니다.

하지만 결과를 확인하니 가장 큰 값이 아니였습니다. 

다음 칸을 가장 큰 값을 밟더라도 그 다음 칸을 같은 열을 밟으면 안되므로 가장 큰 값이 아니게되었습니다.

# 회고

DP를 많이 풀어보지 않아서, DP 접근을 잘 생각하지 않는 것 같습니다.

O(n)
