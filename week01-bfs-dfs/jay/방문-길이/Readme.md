## 방문 길이

- **알고리즘**: 구현, Set, 좌표 시뮬레이션
- **접근법**
  - 명령어에 따라 좌우상하 이동
  - 처음 보는 길을 Set에 저장하고 확인

- **막혔던 점**
  - 처음 보는 선분을 visited[r][c] 로 저장하려고 함.
  - 여기서 문제가 선분을 저장하는게 쉽지가 않음....
  - 그래서 차라리 시작점과 끝점을 한번에 Set에 저장
- **시간 복잡도**
  - 명령어 길이 N만큼 확인 O(N)
  - Set 조회 및 추가 평균 O(1)
  - 즉 O(N)이면 가능

- **배운 점**
  - 지나간 선분이나 좌표로 생각하기 힘든 것들은 set을 쓰지
  - set에는 append가 아니라 add를 사용해야 한다.
