## 게임 맵 최단거리

- **알고리즘**: BFS, Queue
- **접근법**
  - 시작점에서 도착점까지 최소 이동 횟수를 구하는 문제
  - 모든 이동 비용이 동일하므로 BFS 사용
  - 상하좌우로 이동하며 방문하지 않은 좌표를 Queue에 추가

- **생각해야 되는 것**
  - 최단거리 문제인가?
  - 간선의 가중치가 동일한가?
  - 방문 처리는 언제 할 것인가?
  - 좌표가 맵의 범위를 벗어나지 않는가?

- **시간복잡도**
  - 각 칸을 최대 한 번 방문
  - 맵 크기가 `N x M`
  - `O(N * M)`
