## 단어 변환

- **알고리즘**: BFS, 그래프 탐색
- **접근법**
  - 각 단어를 하나의 노드로 생각
  - 한 글자만 다른 단어끼리 이동 가능
  - 최소 변환 횟수를 구해야 하므로 BFS 사용
  - 현재 단어에서 변환 가능한 단어를 Queue에 추가

- **생각해야 되는 것**
  - 문자열 문제를 그래프로 볼 수 있는가?
  - 두 단어가 연결되는 조건은 무엇인가?
  - 방문한 단어를 다시 볼 필요가 있는가?
  - `target`이 `words`에 없는 경우는 어떻게 처리할 것인가?

- **시간복잡도**
  - 각 단어마다 다른 단어들을 비교
  - 단어 개수 `N`, 단어 길이 `L`
  - `O(N^2 * L)`
